# AI Experiments

A collection of experiments across machine learning, neural networks, genetic algorithms, and local LLM agents.

## Projects

### [Stick Walker Simulation](simulations/stick-walker)
2D physics simulation where a bipedal ragdoll figure evolves locomotion using genetic algorithms and joint actuators.

### [Neural Network Car](simulations/nn-car)
Autonomous 2D car simulation navigating a track using raycast distance sensors and a feedforward neural network evolved across generations.

### [Go LLM CLI](go-llm-cli)
Go command-line tool for interacting with local LLMs, streaming completions, and evaluating structured responses.

### [Local RAG Service](local-rag-service)
Docker Compose stack orchestrating SearXNG, llama.cpp (Hermes 3 8B GGUF with CUDA acceleration), and a FastAPI tool-calling proxy for local retrieval-augmented generation.

### [LLM from Scratch](llm-from-scratch)
Python walkthrough constructing an autoregressive language model from first principles, from character-level bigrams up to transformer attention.

### [Godot NPC Agent](godot-npc-agent)
Godot 4 prototype connecting game world entities to local LLMs for emergent NPC interactions, spatial awareness, and dialogue generation.
