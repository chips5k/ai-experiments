# Go Neural Network Experiments

CLI-based neural network and classifier implementations written from scratch in Go with zero external dependencies.

## Projects

- `cmd/simple-nn`: Multi-layer neural network with forward propagation, backpropagation gradient descent, sigmoid activations, and model serialization/deserialization.
- `cmd/fruit-classifier`: Multi-dimensional feature classifier categorizing objects by dimensions and weights.

## Usage

```bash
go run ./cmd/simple-nn
go run ./cmd/fruit-classifier
```
