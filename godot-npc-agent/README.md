# LLM NPCs

> **Curiosity Experiment:** A Godot 4 exploration prototyping autonomous NPC dialogue and decision-making driven by local LLM agent loops.

## Overview

Experiments with integrating local language model inference into game engines:
- Uses Godot engine for spatial entity management, interaction boundaries, and viewport rendering.
- Prototypes event triggers dispatching game context to local LLMs for non-scripted dialogue generation.

## Getting Started

1. Install [Godot Engine 4.x](https://godotengine.org/).
2. Open Godot, click **Import**, and select this directory (`godot-npc-agent`).
3. Press **F5** to run the project.
