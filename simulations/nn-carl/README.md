# 2D Neural Network Carl Simulation

A lightweight in-browser neural network experiment exploring autonomous steering and navigation with Carl the NN.

## Overview

- **Feedforward Neural Network**: Multi-layer perceptron with customizable input, hidden, and output layers.
- **Sensor Inputs**: Raycast distance sensors detecting track boundaries and obstacles.
- **Outputs**: Throttle, brake, and steering angles.
- **Zero Dependencies**: Pure vanilla JavaScript implementation.
